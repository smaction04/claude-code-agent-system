# 디스크 정리 스킬

PC 용량을 실측해 안전 등급별로 분류하고, **사용자 승인 후에만** 삭제한다.

## 절대 원칙
- **승인 없이 삭제 금지.** 목록·등급 보고가 1차 산출물.
- **모든 수치는 실측값.** 추정 크기 금지.
- 개인 파일(다운로드 등)은 내용을 먼저 보여주고 항목 단위로 확인.

## 1단계 — 드라이브 용량 실측
```
Get-PSDrive -PSProvider FileSystem | 사용/여유 GB
```
여유 적은 드라이브를 우선 표시.

## 2단계 — 정리 후보 실측 (크기 측정)
안전등급별로:
- **A등급(바로 삭제 OK·자동 재생성)**: npm캐시(`$env:LOCALAPPDATA\npm-cache`)·pip캐시·Temp(`$env:TEMP`)·`C:\Windows\Temp`·휴지통·크롬/엣지 캐시(`...\Default\Cache`)·썸네일·Windows Update 잔재
- **B등급(확인 후)**: 다운로드 폴더·마이그레이션 스냅샷·옮김 끝난 백업
- **C등급(개발 잔재·재설치 필요)**: `.venv`·`node_modules`·`__pycache__`
- **건드리면 안 됨**: AppData 본체·작업폴더·중요 자료 vault·지식 베이스

측정은 `du -sm` 또는 PowerShell `Get-ChildItem -Recurse | Measure-Object Length -Sum`.

## 3단계 — 등급별 표 보고 + 승인 요청
회수 가능 용량 합계 제시. 사용자가 등급/항목 선택.

## 4단계 — 삭제 (승인분만)
- 캐시 폴더는 **폴더 자체는 두고 내용만** 삭제(`Remove-Item 내부항목`).
- 휴지통: `Clear-RecycleBin -Force`.
- 사용 중 잠긴 파일은 건너뛰고 보고.
- **삭제 후 재측정**으로 회수량 실증(자가진술 금지).

## 주의
- 다운로드 폴더엔 경력증명서·업무파일이 섞일 수 있음 → 통째 삭제 금지, 항목 확인.
- 클라우드 동기화 폴더·마이그레이션 백업은 옮김 완료 여부 확인 후.
