# 기업정보 조회 스킬

회사의 공개 기업정보를 **무료로 가능한 끝까지** 조회한다. 비상장사는 재무제표가 비공개임을 정직하게 알리고, 결제 전 "데이터 존재 여부"까지만 무료로 확인해 사용자의 헛돈을 막는다.

## 핵심 원칙 (절대 준수)
- **수치를 지어내지 않는다.** 못 얻은 건 "못 얻음"이라고 명시한다.
- 출처를 항상 함께 적는다 (DART / NICE / 사람인 등).
- 비상장사는 "재무제표 공개 의무 없음 = 제도상 비공개"임을 설명한다.

## 조회 순서 (이 순서대로)

### 1단계 — 회사 특정
- WebSearch로 "회사명 사업자등록번호 / 대표" 검색.
- bizno.net·moneypin.biz에서 사업자번호·대표·주소 확보.
- 동명이인 회사 주의: 주소·대표로 사용자가 찾는 회사가 맞는지 교차확인.

### 2단계 — 기본정보 (무료로 거의 다 나옴)
- **사람인 기업정보**가 가장 풍부: `saramin.co.kr` 검색 → 회사 페이지.
  - Playwright로 `browser_navigate` 후 `browser_evaluate`로 본문 추출.
  - 확보 가능: 대표자·설립일·직원수(국민연금)·업종·주소.
- DART(`dart.fss.or.kr`) 조회 → 결과 있으면 외부감사 대상 = 감사보고서 존재(재무 공개).

### 3단계 — 재무 데이터 "존재 여부" 확인 (결제 전·무료)
- 사람인 회사페이지 → "재무정보" 탭 → 버튼의 `onclick` URL(`view-inner-finance?csn=...`)로 직접 이동.
- 거기서 "신용분석 보고서(NICE/유료)" 링크의 `kiscode`를 확보.
- NICE 상품페이지(`nicebizinfo.com/ep/EP0100M002GE.nice?kiscode=XXX`)로 이동:
  - **재무제표 "국문 샘플" 버튼**을 누르면 샘플 xlsx가 무료 다운로드됨 → 압축 풀어(`sharedStrings.xml`) 어떤 항목(재무상태표·손익·감사의견)이 들었는지 확인.
  - 가격표 확인: 기업분석 요약 7천원 / 재무제표 국문 44,000원 등.

### 4단계 — 미국 회사
- 캘리포니아: `bizfileonline.sos.ca.gov` (단 hCaptcha로 자동 차단됨 → 사용자 직접).
- opencorporates.com도 hCaptcha 빈번. 비상장 미국법인은 재무 공개의무 거의 없음 → 기대 낮음 명시.

## 보고 형식
1. 확보한 기본정보 표 (출처 명기)
2. 재무제표 존재 여부 + (있으면) 가격·포함내용
3. 못 얻은 것 + 이유 (정직)
4. 다음 선택지: ①유료 결제 직전 화면 세팅 ②회사 내부자료 받아 분석 ③여기까지

## 주의
- 기업정보 사이트는 캡차·로그인·429(과다요청)가 흔하다. 막히면 다른 소스로 우회하고, 안 되면 정직하게 보고.
- 결제·로그인은 **사용자 본인 계정**으로만 가능. 어시스턴트는 결제 직전 화면까지만 세팅.
- 임시 다운로드 파일(.xlsx 샘플 등)은 확인 후 자동 삭제.
